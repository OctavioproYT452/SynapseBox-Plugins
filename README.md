# SynapseBox-Puglins

Repositorio de plugins de SynapseBox.

Estructura: `Categoría/nombre-del-plugin/` con `plugin.json` (versión, título, descripción, imágenes…), `images/` y los archivos del plugin (`server.js`, `client.js`, `style.css`…).

Se instalan desde el panel de administración → Plugins → Repositorio. Guía para crear plugins: ver la documentación de SynapseBox.
